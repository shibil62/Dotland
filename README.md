## Features

- Floating island that morphs between a dot, a pill and an expanded panel
- Real system **volume** and **brightness** control
- **Wi-Fi** status, scanning and available networks
- **Bluetooth** controls, plus a connection animation when earbuds or headphones connect
- Built-in settings

## Install

1. Go to the [**Releases**](../../releases/latest) page.
2. Download `Dotland-v1.0.0-win-x64.zip`.
3. Right-click the zip → **Extract All**.
4. Double-click `Dotland.exe`.

No installer, and you do **not** need to install .NET. Everything is bundled.

## Requirements

- Windows 10 (version 1809 or newer) or Windows 11, 64-bit

## "Windows protected your PC" warning

Dotland is a new, independent app and is not code-signed yet, so Windows SmartScreen may show a warning the first time.
Click **More info → Run anyway**. Dotland does not collect, store or send any personal data.

## Updates

New versions are posted on the [Releases](../../releases) page. Download the newest zip, close Dotland, and replace the old `Dotland.exe`.
Click **Watch → Custom → Releases** at the top of this page to be notified of new versions.

## Uninstall

Close Dotland and delete the folder. That's it.
